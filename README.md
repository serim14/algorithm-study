# Algorithm Study

알고리즘 및 자료구조 학습과 코딩테스트 문제 풀이를 기록하는 저장소입니다.

Python을 기반으로 다양한 유형의 알고리즘 문제를 해결하며, 문제 해결 능력과 구현 역량을 꾸준히 향상시키는 것을 목표로 합니다.

## 🎯 Goals

- 자료구조 및 알고리즘의 핵심 개념 이해
- 다양한 문제 유형에 대한 해결 전략 학습
- 효율적이고 가독성 높은 코드 작성
- 꾸준한 문제 풀이를 통한 코딩테스트 역량 강화

## 📂 Repository Structure

| Directory | Description |
|---|---|
| `study/` | 알고리즘 스터디 활동 및 주차별 문제 풀이 |
| `ssafy/` | SSAFY 알고리즘 수업, 과제 및 평가 대비 |
| `swea/` | SWEA 문제 풀이 |
| `programmers/` | 프로그래머스 문제 풀이 |
| `codetree/` | 코드트리 문제 풀이 (GitHub 자동 연동) |
| `company/` | 기업별 코딩테스트 기출 및 유형별 연습 |
| `notes/` | 알고리즘 개념 정리 및 코드 템플릿 |

## 🛠 Tech Stack

- **Language:** Python 3
- **Platforms:** SWEA, Programmers, Codetree
- **Version Control:** Git & GitHub

## 📚 Study Approach

1. **Understand** — 문제의 요구사항과 제약 조건 분석
2. **Design** — 적절한 알고리즘 및 자료구조 선택
3. **Implement** — Python으로 해결 방법 구현
4. **Review** — 시간·공간 복잡도 분석 및 풀이 개선
5. **Document** — 주요 개념과 새롭게 배운 내용 기록

꾸준한 학습과 문제 해결 과정을 기록하며 성장하는 것을 목표로 합니다.
